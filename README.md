# 🏡 NestBKK — Real Estate By Annie

## How to put this website online (step by step)

---

### Step 1 — Install Node.js
Go to https://nodejs.org and download the **LTS** version. Install it.

---

### Step 2 — Upload to GitHub
1. Go to https://github.com and create a free account
2. Click **"New repository"** → name it `nestbkk` → click **Create**
3. Upload ALL these files by dragging them into GitHub

---

### Step 3 — Deploy on Vercel (free)
1. Go to https://vercel.com and sign up with your GitHub account
2. Click **"Add New Project"**
3. Select your `nestbkk` repository
4. Click **Deploy** — done! ✅

Your site will be live at: **nestbkk.vercel.app**

---

### Step 4 — Get your own domain (optional)
Buy `nestbkk.com` at https://namecheap.com (~฿350/year)
Then connect it in Vercel → Settings → Domains
